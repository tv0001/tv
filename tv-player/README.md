# TV Player

原生 Kotlin 写的影视聚合播放器（手机 / 安卓 TV 盒子），不依赖自建服务端，没有 jar / js / python 爬虫运行时。

## 功能

- **热播榜**：发现页顶部是热播电影 / 剧集 / 综艺 / 动漫（豆瓣榜单，带评分和封面，缓存 3 小时）；点任意一项就在所有源里搜这个片名。采集站自己的点击量全是 0，所以榜单只能取自外部
- **追剧提醒**：收藏的剧集每小时在后台检查一次（App 没打开也会检查），有新集就发系统通知，点通知直接打开这部剧；「我的」页的卡片会标「新」和「更新 +N 集」，底部「我的」标签上显示有几部有更新。每部剧只在集数增加时通知一次
- **字幕与音轨**：播放设置里可以切换字幕、切换音轨（多音轨时才显示），还能导入本地的 srt / vtt / ass 字幕文件；GBK 编码的中文字幕会自动识别
- **画面比例**：播放设置 → 画面，可选适应（默认，留黑边）、填满（裁切）、拉伸，选择会记住
- **直播回看**：M3U 直播源里写了 `catchup-source` 的频道，播放设置里的「节目回看」可以选最近 7 天内播过的节目来看（需要节目单，回看地址按源提供的模板生成）；选「回到直播」回到实时画面。TVBox txt 格式没有回看信息，不支持回看
- **手机遥控**：电视上「用手机输入或遥控电视」里，手机网页有方向键、确定、返回、播放暂停、快进快退、换台、音量按钮，按键会原样发到电视上当前的界面。点「保持遥控 30 分钟」可以关掉二维码后继续用
- **电视桌面「继续观看」**：在 Android TV 桌面的继续观看行里显示最近看的剧，点击直接打开这部剧并接着看（只在电视上写入，手机没有这个功能）
- **跳过片头片尾 / 倍速记忆**：播放设置里可以给一部剧设置跳过片头、片尾的秒数（每一集都生效），倍速选择会记住
- **睡眠定时**：15 / 30 / 60 分钟或播完这一集后自动暂停
- **切出 App 时**：可选暂停（默认）、后台继续放声音（带通知栏停止按钮）、小窗播放（画中画）
- **搜索筛选和排序**：结果多时可按年份、类型、清晰度（按片源备注判断）、来源筛选，按年份 / 源数量 / 片名排序
- **直播**：节目单（现在播什么、接下来是什么，数据来自 epg.112114.xyz，连不上就不显示）；电视遥控器上下键或频道键换台、数字键直接选台（如 13 → CCTV13）；手动选过的线路会按频道记住
- **手机给电视输入**：电视上扫码打开一个局域网网页，用手机输入搜索词、添加点播源或直播源，不用在电视上打字（窗口关闭后地址失效）
- **电视详情页**：点播先进入详情页（模糊海报背景、小窗预览、简介、线路、分段选集），确认键全屏，返回键回到详情页；播放时不锁屏
- **热播推荐样式**：默认顶部标签（剧集 / 电影 / 综艺 / 动漫分页切换，一页一个网格）；设置里可改回「分组横滑」（几个榜单上下排开，每个榜单左右滑）
- **夸克网盘**：设置 → 夸克网盘 → 扫码登录（用手机上的夸克 App 扫电视上的二维码），之后在「我的」页或设置里打开网盘，按文件夹浏览，点一个视频就播放，同一文件夹里的视频是选集，线路是「原画 / 超清 / 高清 / 普通」（原画是文件本身，其余是网盘的转码流）。用的是夸克电视端的开放接口（和 OpenList 的 QuarkTV 驱动相同），扫码后换取凭证这一步经过 api.extscreen.com；凭证只存在本机，不进备份。「添加分享链接」（网盘页或设置里）：粘贴 `pan.quark.cn/s/…` 链接（可带提取码），不用登录就能浏览分享里的文件；点一个视频时会把它转存到你网盘的「TV Player / 分享标题」文件夹再播放，这一步需要另一套登录——设置里的「网页版扫码登录」（网页版 cookie 只存在本机，不进备份）。播放优先走电视端登录（有原画 / 超清 / 高清 / 普通几条线，原画文件的下载地址可能很慢，卡住会自动换线），没有电视端登录就只用网页版登录播放原画。光盘镜像（.iso）播放器打不开，会提示并跳过；转存的文件占你的网盘空间，用完在夸克里自己删。订阅里的阿里 / UC 等 `type: 3` 网盘爬虫站点仍然不支持
- **短剧**：底部（电视、平板为侧栏）多一个「短剧」标签页：各点播源「短剧」分类里的片子按更新顺序排成网格，滚到底自动加载下一页，同名片子合并成一张卡片；点开时先花最多 3 秒在所有源里找同名条目并进这张卡，再进播放页，这样只有一个源的片子也有线路可换。发现页也多一个「短剧」榜单（标签或横滑行），列出各点播源「短剧」分类里最近更新的片子（按片名去重，片名末尾的「AI」「Ai漫剧」标记会去掉）；点开和别的片子一样跨源搜索播放。搜索结果的类型筛选里也有「短剧」。源分类名里带「擦边」的和成人分类一样被排除
- **热播榜顺序**：热播剧集、电影、综艺、动漫、短剧、最近更新
- **跨源搜索**：同时查所有 CMS 点播源（Apple CMS JSON），每个源独立超时，结果边返回边显示，同名影片自动合并成一张卡片
- **智能选线**：点开就用第一条线路播放，不等测速；优先用直接是视频地址（m3u8 / mp4）的线路，跳过要先解析的分享页。这部片上次能播的源和线路、直播频道上次能播的线路会先试。4 秒还没起播才在后台测其它线路，有流畅的就换过去；起播后立即停止测速，不和正在播放的线路抢网速。起播失败的线路所在服务器 6 小时内排到最后，其它源的详情在后台并行预取，换源不用再等。设置 → 显示与播放 → 选线方式可改成「智能 / 始终测速 / 按顺序」；手动选过线路后以手动为准
- **自动换源**：同一集（按集名对应）在所有已加载的源、所有线路里找候选，同一部片先试实测播放速度快的源（`cms.json` 的顺序）；播放报错或 20 秒没起播，自动换下一条（跨线路、跨源）。已经放起来的线路偶尔断网、超时或解码出错时，先等 2 秒在原线路、原位置重试一次，一分钟内又出错才换线；直播卡得太久落后于直播窗口时跳回最新画面
- **去广告**：按订阅里的 `rules`（和 TVBox 写法相同）剔除点播 m3u8 里插的广告分片，例如暴风的 `adjump`、非凡和量子插在两个 DISCONTINUITY 之间的那段。只处理点播列表；剔掉超过一半时长时视为规则不适用，原样播放
- **直播**：TVBox txt / M3U 列表，同名频道多条线路，卡住自动切线路
- **DLNA 投屏**：自己实现 SSDP 发现 + AVTransport 控制，不依赖 Google Play 服务（电视盒子大多没有）
- **手势**：左右滑动调进度，左半屏上下滑调亮度，右半屏上下滑调音量（提示带图标和进度条）；双击左右两侧快退 / 快进 10 秒（接着在同一侧单点继续累加），双击中间暂停；长按 2 倍速，顶上有「倍速播放中」提示
- **横屏全屏**（手机，参照腾讯视频 / B 站）：顶栏是返回、片名 · 集名、时间和电量、投屏、设置，跟控制栏一起淡入淡出；控制栏右下角有「倍速」（选过就显示当前倍速）和「选集」，倍速、选集、播放设置都从右边滑出，点左边的画面收起；左边中间的锁键锁屏，锁住后手势和控制栏都不响应、屏幕方向固定，点画面只露出锁键，返回键也先提示解锁
- **电视首页「继续观看」**：标签布局下第一个标签是「继续观看」（海报带进度条），点开直接进详情页接着播；在标签之间左右移焦点就切页，不用按确认，从下面的网格按上回到当前标签，不会误切页
- **电视搜索焦点**：点热播、历史发起搜索后，结果一出来焦点就落在第一个结果上（以前焦点掉回左侧导航，要自己按过去）；状态行不再抢焦点；侧边导航的焦点有蓝色描边
- **电视控制栏进度条**：全屏控制栏的时间下面有一条进度条，同时显示已缓冲到哪
- **平板播放页**：画面左上角有返回、片名 · 集名、时间电量（跟控制栏一起出现），底栏有「倍速」「选集」，倍速、选集、播放设置从右边滑出；右侧面板的收藏、投屏、设置排成一排，选集能多显示几行
- **手机竖屏播放页**（参照腾讯视频 / 爱奇艺）：小窗顶到状态栏，返回键浮在画面上；下面是片名、评分年份类型、「简介 ›」（弹出导演、主演、全文），操作多了「下载」；正在播的那一集带跳动的音柱；起播前小窗里先显示模糊的海报
- **缓冲网速、中途卡住自动换线**：缓冲时转圈下面显示网速；播放中途连续缓冲 15 秒（没报错，只是不来数据），而后台测速里下一条线路是流畅的，就从当前位置换过去（每集最多一次；没有测过流畅的线路时不换，免得是自家网络慢时把每条线路都判失败）。点播反复小卡（3 分钟内已经卡过 2 次）时，再卡 3 秒就换，不等满 15 秒；换过之后隔 2 分钟可以再换。直播中途缓冲 3 秒就重新测其它线路，卡满 8 秒换到测出来流畅的一条（都不流畅就不换）；换过之后隔 2 分钟才会再因为卡住换线。换线、换源都按集名找同一个视频（「第01集」=「第1集」=「EP01」，「第1期(上)」=「第1期上」），对不上的线路不用：综艺各源分集方式不同，按序号会跳到别的期
- **空闲预缓存**：点播 m3u8 暂停时把后面 10 分钟、播放中缓冲已满（网络闲着）时把后面 5 分钟下进磁盘缓存，播放器一开始缓冲就停下让路；播放缓存上限 1 GB（不超过可用空间的四分之一），旧的先删。计费网络、关了多连接预取时不做
- **电视海报、导航**：片名太长时聚焦后滚动显示；侧边导航的焦点是一层半透明浅色底，焦点在内容区时导航压暗
- **续播提示**：从观看记录接着播时，画面左下角提示「已从 12:34 继续播放」，手机上带「从头播放」（设了跳过片头的照样跳过），6 秒后淡出
- **继续观看进度条**：发现页和「我的」页的继续观看海报底部画一条这一集看到哪的进度线（快看完的不画）；没有海报或海报加载失败时显示一个淡淡的胶片图标
- **选集按名字排列**：综艺「20261022-01」这类长集名自动少排几列，不再每格都截成「202610…」
- **竖屏短剧**（手机）：详情页的小窗按画面比例撑高（最多半屏），往上滚选集时先收矮到 16:9，滚回顶部再往下拉又撑高；把小窗下面那一栏（顶上有「﹀」把手）往下拖，这一栏跟着手指往下走、画面放大进竖屏全屏（快速往下一甩也行；从选集列表里拖时，列表没在顶上就先滚列表）；全屏里中间上滑下一集、下滑上一集，像抖音一样整页跟着手指走，那一集先用海报卡片顶着、第一帧出来再淡出（滑过 1/5 屏或快速一甩就切，不够就弹回）；右下角常驻的「∧」按钮退回小窗
- **本地库**：收藏、观看历史（记住集数和进度，下次续播），用 Android 自带 SQLite。播放中手动换线路或换源，以及自动换源，都从当前位置接着播，不会回到开头；换过去的那条如果是「一集合全集」这类长度不同的流，位置超出时就从头播
- **订阅**：内置一份点播源和直播源，打开 App 时每 12 小时自动从订阅目录更新；可手动更新、导入任意 TVBox 配置 / TXT / M3U 地址
- **自定义源**：设置 → 管理点播源和直播源。添加自己的 CMS 接口（添加前先真实搜索一次检测）或直播列表地址；每个点播源可单独开关、测速、删除；自定义直播列表会和订阅里的同名频道合并线路
- **应用内更新**：启动时（每 12 小时）和设置里的“检查更新”读订阅目录下的 `app-version.json`，有新版就弹窗，下载后校验 SHA-256 再调用系统安装器。下载可以点「后台下载」收起（下载期间用一个前台服务保持网络，通知栏显示进度，完成后在前台直接弹安装、在后台发通知，下次打开 App 也会直接提示安装）；下载中断（断网、杀进程、取消）会保留已下载的部分，下次用 Range 续传，校验仍然覆盖整个文件；安装时 Android 要求新包和已装的签名一致，所以更新源被篡改也装不上别人的包。电视上第一次需要在系统里允许“安装未知应用”
- **备份**：订阅、收藏、历史、搜索记录导出成一个 JSON 文件，换设备时导入
- **自动检测清晰度**：播放时读取视频的真实分辨率（4K / 1080P / 720P…），显示在播放状态里，并记在线路标签上，换线路时一眼看出哪条更清楚。自适应码率的流默认不会超过屏幕物理分辨率
- **电视分辨率适配**：不同电视和盒子对同一块屏幕报告的密度很乱（1080p 报 160 / 240 / 320dpi 都有），电视模式下按真实像素反推密度，让界面统一排成约 960dp 宽；设置里可以微调“偏小 / 自动 / 偏大”
- **平板模式**：最短边 600dp 以上自动识别为平板，用侧边导航栏、更大的海报网格，横屏播放页是“左画面 + 右面板”；也可在设置里手动指定
- **TV 版**：同一个 APK。电视上自动换成左侧导航栏 + 大海报网格，遥控器方向键全程可用（焦点放大高亮；播放页左右键快进快退 10 秒，上下键进右侧面板）；盒子不报告自己是电视时，在设置里把“界面模式”手动选成“电视”（或“平板”）

- **遥控器按住快进**：电视上按住左右键越按越快（每秒 20 秒 → 1 分钟 → 3 分钟，短片有上限），按住时只显示要跳到哪，松手才跳一次
- **下一集提示**：一集离结束 10 秒（设了跳过片尾就从片尾算）时右上角出现「下一集」倒计时；手机上可点「立即播放 / 取消」，电视上确认键立即播放、返回键取消。短于 5 分钟的（短剧）照旧直接连播
- **字幕大小和时间**：播放设置里字幕可选小 / 标准 / 大 / 特大；导入的字幕可以按 0.5 秒提前或延后（重写一份字幕再从原位置接着播）
- **崩溃日志**：未捕获的异常记在本机（地址只留域名、token 等打码），设置页可查看、复制、清空；电视上也能在手机网页里看
- **播放日志**：卡顿、掉帧、原线路重试时记下线路、解码器、最近的请求耗时，退出时写一份小结（显示/掉帧帧数、去广告剔除了多少），在设置或手机网页里看
- **隧道播放**（电视，默认关）：设置里开启后，解码后的画面直接交给显示硬件，部分电视更顺；设备不支持时自动按普通方式播放
- **自动换源**：同一集（按集名对应）在所有已加载的源、所有线路里找候选，同一部片先试实测播放速度快的源（`cms.json` 的顺序）；播放报错或 20 秒没起播，自动换下一条（跨线路、跨源）。已经放起来的线路偶尔断网、超时或解码出错时，先等 2 秒在原线路、原位置重试一次，一分钟内又出错才换线；直播卡得太久落后于直播窗口时跳回最新画面
- **去广告**：按订阅里的 `rules`（和 TVBox 写法相同）剔除点播 m3u8 里插的广告分片，例如暴风的 `adjump`、非凡和量子插在两个 DISCONTINUITY 之间的那段。只处理点播列表；剔掉超过一半时长时视为规则不适用，原样播放
：按片源帧率把电视切到整数倍的刷新率，24 帧电影在 60Hz 电视上不再一顿一顿；片源没写帧率时从帧时间戳估
- **AC3 / EAC3 / DTS 音轨**：设备没有对应硬解时用 ffmpeg 软解（Jellyfin 编译的 media3 ffmpeg 扩展，只打包 ARM），不会有画面没声音
- **接收手机投屏**（DLNA，电视默认开）：应用打开时以「TV Player（型号）」出现在手机视频 App 的投屏列表里，支持暂停、拖动、停止、音量
- **网络存储**：WebDAV（OpenList / Alist 的 /dav、群晖、威联通）和 SMB（Windows 共享、NAS），按文件夹浏览，同一文件夹的视频是选集；电视上可以用手机网页填地址和密码（只存本机，不进备份）
- **局域网同步**：手机和电视在同一个 Wi-Fi 下，用 4 位配对码合并收藏和观看记录（进度以新的为准，收藏只增不减）
- **离线下载**（手机、平板）：播放设置里「下载这一集」，多码率只下一种（不超过 1080P），默认只在 Wi-Fi 下载；「我的 → 下载」里离线播放
- **搜索联想和首字母键盘**：输入时按包含或拼音首字母联想本地片名，中文再查豆瓣联想；电视上搜索框下面是首字母键盘（打「jjc」就能搜「嫁金钗」）
- **分类筛选**：搜索栏的筛选按钮，按电影 / 剧集、类型、地区等筛选豆瓣片单，点一部在所有源里搜

## 不支持

- type 0（XML CMS）和 type 3 里的 js / python 爬虫站点：需要运行时，这里直接跳过。type 3 的 jar 爬虫站点默认也不用，可以在设置里打开（见下）
- jar 爬虫站点（实验，设置里默认关闭）：订阅的 spider.jar 和站点自带的 jar 在单独的爬虫进程里加载（不调用 jar 的 `Init.init`，它会执行原生程序），本地代理开在 127.0.0.1:9978；播放结果按 TVBox（FongMi）的约定处理（请求头、DASH、playUrl、parses 解析接口、网页嗅探）。网盘资源站没有网盘登录时给不出线路，本应用自己从站点详情页找夸克分享，播放时转存到你的网盘再放（要夸克网页版登录，只认夸克）。磁力链接、jar 自己的配置中心 / 扫码登录不支持；夸克等网盘登录加密保存，不交给 jar
- 弹幕、在线字幕搜索（字幕要自己导入）
- 投屏只有 DLNA（发送和接收），没有 Chromecast / AirPlay；爱奇艺、腾讯视频等用自家协议投屏的 App 找不到 TV Player

## 构建

需要 JDK 17+、Gradle 9.x、Android SDK 35。

```bash
cd tv-player
gradle assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
gradle assembleDebug -Plegacy   # 兼容包：app/build/outputs/apk/debug/app-legacy-debug.apk
```

### 兼容包（Android 5.0 – 7.x 的老电视、老盒子）

主版本最低 Android 8.0。带 `-Plegacy` 打出的兼容包最低 Android 5.0，代码和主版本是同一份，区别只有：

- 老系统没有的功能自动关掉：手机小窗播放（8.0）、按片源切换刷新率（6.0）、通知分类（8.0）
- 补了一套 Mozilla 根证书（`app/src/legacy/resources/cacert.pem`，取自 https://curl.se/ca/cacert.pem）：Android 7.1.1 以下的系统不认 Let's Encrypt、DigiCert G2 等新根证书，不补的话豆瓣、很多片源都连不上。只在兼容包、只在 7.x 及以下的系统生效（见 `LegacyTls`）
- 老系统画不出来的资源换成兼容写法（`app/src/legacy/res`：桌面图标、电视横幅、海报占位图）；海报和源列表的焦点框在 6.0 以下画成背景（见 `legacyFocusRing`）
- 自动更新读 `app-version-legacy.json`，不会升级成装不上的主版本

两种包共用 `app/build`，打另一种时 Gradle 会清掉上一种的产物：打完一种先签名拷走，再打另一种。Android 4.4 不支持（播放器 Media3、OkHttp 等依赖最低都是 5.0）。

## 发布新版本

```bash
# 1. 版本号（也可以直接改 app/build.gradle 里的默认值）
gradle assembleRelease -PappVersionCode=3 -PappVersionName=1.0.2

# 2. 用【固定的】密钥签名。以后每个版本都必须用同一把，否则已装的用户升级会失败
$ANDROID_HOME/build-tools/<版本>/apksigner sign --ks <你的.keystore> \
  --out releases/TV-Player-1.0.2.apk app/build/outputs/apk/release/app-release-unsigned.apk

# 3. 生成版本说明（读取 output-metadata.json 里的版本号，计算 sha256 和大小）
python3 scripts/make-update-manifest.py releases/TV-Player-1.0.2.apk "<APK 的下载地址>" "更新说明" > ../tvbox-check/out/app-version.json
```

兼容包同样走一遍，版本号和主版本保持一致；第 3 步要紧接在兼容包的构建之后跑（读的是同一个 output-metadata.json）：

```bash
gradle assembleRelease -Plegacy -PappVersionCode=3 -PappVersionName=1.0.2
# 兼容包【必须保留 v1 签名】（不要加 --v1-signing-enabled false）：Android 5.0 / 6.0 只认 v1，
# 只有 v2 签名的包会装不上（INSTALL_PARSE_FAILED_NO_CERTIFICATES）
$ANDROID_HOME/build-tools/<版本>/apksigner sign --ks <你的.keystore> \
  --out releases/TV-Player-1.0.2-legacy.apk app/build/outputs/apk/release/app-legacy-release-unsigned.apk
python3 scripts/make-update-manifest.py releases/TV-Player-1.0.2-legacy.apk "<APK 的下载地址>" "更新说明" > ../tvbox-check/out/app-version-legacy.json
```

没有发布过 `app-version-legacy.json` 时，兼容包里点「检查更新」会提示检查失败（所有镜像都是 404，显示的是其中一个连不上的镜像的错误）。

把 APK 和 `app-version.json` 提交到仓库，已安装的 App 就会在下次检查时提示更新。`releases/` 里请保留最近五个版本：公共代理（gh-proxy）会缓存版本说明一段时间，旧说明指向的 APK 如果被删掉，用户会下载失败。当前 `releases/` 里的包用的是本机 Android debug 密钥，只适合自己用；要给别人用，请换成自己保管的发布密钥。
